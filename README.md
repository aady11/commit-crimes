## 🚨 The Problem

Git is one of the most powerful tools developers use, yet it's also one of the most intimidating.

Most beginners memorize commands without understanding **what is actually happening**.

**Commit Crimes** transforms common Git mistakes into interactive browser puzzles, making learning visual, intuitive, and fun.

---

## 🎯 What is Commit Crimes?

Commit Crimes is a browser-based game where every level is a Git disaster.

Instead of reading documentation, players solve real-world Git scenarios through interaction.

Examples include:

- 🚨 Direct Commit to `main`
- 🌿 Deleted Branch
- 🔀 Merge Conflict
- 💥 Force Push Disaster
- 🔑 Secret API Key Leak
- ✏️ Wrong Commit Message

No terminal required.

Just think, interact, and save the repository.

## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/aady11/commit-crimes.git
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```

## 💡 Why I Built This

While learning Git, I realized that many tutorials teach **commands**, but very few teach **understanding**.

So instead of building another tutorial website, I decided to build a game.

The goal wasn't just to teach Git—it was to make learning feel rewarding and memorable.
